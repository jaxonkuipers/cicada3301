# Corpus boundary

This directory contains Cicada source material, faithful transcriptions, and accepted solved
plaintext. It is not a hypothesis or research-memory store.

- `communications/` contains messages attributed to Cicada. A file's presence here does not by
  itself establish that its signature, attribution, or filename metadata has been independently
  verified.
- `liber-primus/images/` contains the published page images.
- `liber-primus/transcription/` contains community-produced transcriptions of those images.
- `liber-primus/solutions/` and the solved rows in `sentences.csv` contain accepted, reproducible
  solves only.
- `mabinogion/` contains the historical ciphertext and corresponding public-domain plaintext used
  in the accepted 2012 solution.

Community theories, proposed cribs, abandoned attempts, and disputed claims belong only in the
raw [`../discord/`](../discord/) exports. Derived research artifacts should be produced by a
research run and stored with that run, not promoted into this corpus.
