# Corpus boundary

This directory contains Cicada source material, faithful transcriptions, and accepted solved plaintext arranged by the public puzzle in which each object entered the solve.

Start with the root [`HISTORY.md`](../HISTORY.md). It reconstructs the 2012, 2013, and 2014 routes and distinguishes publication order from signature time. The machine index [`communications.csv`](communications.csv) is also the order returned by `lib.corpus.load().communications`.

| Path | Historical role |
| --- | --- |
| [`2012/`](2012/) | first recruitment puzzle, including the subreddit Mabinogion ciphertext/plaintext |
| [`2013/`](2013/) | second puzzle and the original Gematria Primus table |
| [`2014/`](2014/) | third puzzle, its messages, and Liber Primus as the route's unresolved output |
| [`2015/`](2015/), [`2016/`](2016/), [`2017/`](2017/) | later authenticated communications |
| [`identity/`](identity/) | Cicada's OpenPGP public key; identity material, not a message |

The corpus is intentionally incomplete as a carrier archive. Missing original images, audio, live services, and individualized material are called out in the history rather than silently implied to exist here. A file's presence does not by itself establish attribution; signature and source provenance are recorded in the relevant findings.

Community theories, proposed cribs, abandoned attempts, and disputed claims belong in the raw [`../discord/`](../discord/) exports or a research run, not in canonical corpus data.
