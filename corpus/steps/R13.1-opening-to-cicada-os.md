**Dependencies consumed.** None from retained route state. This new public entry reused the OutGuess method demonstrated in 2012.

**Artifact and action.** OutGuess returned a signed riddle and three-part book code. “A book whose study is forbidden / Once dictated to a beast; / To be read once and then destroyed” selected Aleister Crowley's *Liber AL vel Legis*. **Resulting state.** The Dropbox object was a roughly 130 MB bootable ISO with `BOOT`, `DATA` and `AUDIO` directories. The canonical directory audit records `BOOT/3301.IMG`, `AUDIO/761.MP3` and the data files `560.13`, `560.17` and `_560.00`.

**State handed forward.** The ISO, `761.MP3`, retained data files and Twitter handle pass to R13.2 and remain available through the 2013 route.

**Evidence.** The signed book code is [`2013-01-opening-book-code.asc`](../2013/communications/2013-01-opening-book-code.asc); the surviving signed Cicada OS message is [`2013-01-cicada-os-message.asc`](../2013/communications/2013-01-cicada-os-message.asc).
