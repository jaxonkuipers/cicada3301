# R12.1 — `final.jpg` to the Mabinogion subreddit

A 509×503 JPEG named `final.jpg`, preserved as `1CcV1.jpg`, opened “Hello. We are looking for highly intelligent individuals” and said a message was hidden in the image. Its appended text ended `TIBERIVS CLAVDIVS CAESAR says "lxxt>33m2mqkyv2gsq3q=w]O2ntk"`. A Caesar shift of four produced `http://i.imgur.com/m9sYK.jpg`; the duck image's “guess how to get the message out” wording selected OutGuess. Running `outguess -r 1CcV1.jpg` returned a 76-entry book code and `http://www.reddit.com/r/a2e7j6ic78h0j/`.

The subreddit supplied ciphertext and two more carriers: `KXLOP.jpg` (“Welcome”) and `8D7hN.jpg` (“Problems?”). Those objects and the book code pass to [R12.2](../R12.2/); the original dimensions return as operands in [R12.3](../R12.3/). The moderator names `CageThrottleUs` and `ImagoOnNib` are anagrams of Charlotte Guest and Mabinogion.

The accepted source material begins with a copy posted to 4chan `/b/` thread `372100808` at `2012-01-04 16:28:15`; the first upload, other board threads and complete custody chain are unavailable. The accepted text and first surviving signed route messages are preserved with [R12.2's artifacts](../R12.2/artifacts/).
