# R14.4 — onion 4's koan, instruction and route grid

Onion 4 initially displayed another 256-byte hex string under `<!--3301-->`, then served a signed gzip carrier containing four images now assembled as introduction pages 06, 07, 09 and 08. They formed `0.2 A KOAN` and an instruction to do four unreasonable things.

OutGuess on intro-08 yielded an unsigned grid. Transposing it with fixed column order `1736254` read `TO BELIEVE TRUTH IS TO DESTROY POSSIBILITY`, the locator `q4utgdi2n4m4uim5`, and residual `9133`. The 16-character hostname, koan pages and residual pass to [R14.5](../R14.5/); older walkthroughs sometimes append `9133`, although version-2 onion hostnames contain 16 characters.

The carrier is [preserved here](artifacts/communications/2014-01-fallen-behind-outguess-08.asc). Its historical placement supports the unsigned grid's route role. The 3301-labelled 256-byte string has no established operation. Its hex is preserved as [`onion4-3301.hex`](artifacts/onion4-3301.hex), 256 bytes read 2048 bits wide, from `scream314/cicada3301` commit `fa795931b7e50bbb3b90322c8e456bcad8f5f034` (`assets/2014/stage05/allstrings`, label `3301`), byte-identical to the copy pasted in Discord message `21573` on 2021-02-08. Its bytes are uniform-random by entropy and byte count, composite, and share no factor with the other three 2048-bit blocks of the route. Together with the 256-byte block printed on Liber Primus pages 49–51 in [R14.7](../R14.7/), the route carries four labelled 2048-bit blocks without a consumer.
