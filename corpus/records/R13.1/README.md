# R13.1 — opening image to Cicada OS

On 4–5 January 2013, `232.jpg`, preserved as `gqvvmk.jpg`, appeared in several 4chan `/b/` and `/x/` threads with “Hello again” and said the first clue was hidden in the image. OutGuess returned a [signed riddle and three-part book code](artifacts/communications/2013-01-opening-book-code.asc). “A book whose study is forbidden / Once dictated to a beast; / To be read once and then destroyed” selected Aleister Crowley's *Liber AL vel Legis*; chapter, verse and character addressing yielded `https://www.dropbox.com/s/r7sgeb5dtmzj14s/3301`.

The Dropbox object was a roughly 130 MB bootable ISO with `BOOT`, `DATA` and `AUDIO` directories. Its canonical audit records `BOOT/3301.IMG`, `AUDIO/761.MP3` and data files `560.13`, `560.17` and `_560.00`. Booting printed primes through 3301, paused at 1033 and 3301, then displayed `@1231507051321 / The key is all around you. / Good luck. / 3301`; the surviving signed OS message is [preserved here](artifacts/communications/2013-01-cicada-os-message.asc).

The ISO, MP3, data files and Twitter handle pass to [R13.2](../R13.2/) and remain available through the 2013 route. Several opening threads are reported, while the complete first-upload custody chain is unavailable.
