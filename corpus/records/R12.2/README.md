# R12.2 — subreddit state to the telephone number

OutGuess on R12.1's `KXLOP.jpg` produced a [signed key announcement](artifacts/communications/2012-01-key-announcement.asc): future messages would use OpenPGP key `7A35090F`. OutGuess on `8D7hN.jpg` produced the signed instruction [“The key has always been right in front of your eyes”](artifacts/communications/2012-01-key-in-front-of-you.asc).

The full subreddit name `a2e7j6ic78h0j7eiejd0120` and its header encode the repeating shifts `10,2,14,7,19,6,18,12,7,8,17,0,19,7,14,18,14,19,13,0,1,2,0`. Applying them to the subreddit text recovered Charlotte Guest's *Mabinogion*. Addressing that [accepted text](artifacts/mabinogion/) with R12.1's 76-entry book code, omitting full stops, read `CALL US AT US TELEPHONE NUMBER TWO ONE FOUR THREE NINE OH NINE SIX OH EIGHT`.

The resulting number was `(214) 390-9608`, or `+1 214-390-9608`. The number and verified signing key pass to [R12.3](../R12.3/) and the later 2012 route. The original subreddit layout is gone; its accepted plaintext, operations and signed carriers survive.
