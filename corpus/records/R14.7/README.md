# R14.7 — shared onion-7 delivery and Liber Primus

R14.6's signed locator led to `ky2khlqdf7qdznac.onion`, an HTML page titled `133` with `<div id="331">` and images `0.jpg` through `57.jpg` in order. Those 58 body images joined the 17 introduction images accumulated during the route to form the 75-image Liber Primus. The body contains runic prose, illustrations, layout and printed marks, numeric structures, the page-49–51 256-byte interruption, page 56's verified 512-bit value, and readable ending pages 56–57.

Eight indexed sections, `0.5` through `0.12`, remain unsolved and contain 12,956 runes. The [corpus directory](artifacts/liber-primus/) holds the canonical images, transcriptions, accepted plaintext and measurements; its compact README describes the data contract, while [PROVENANCE.md](PROVENANCE.md) records custody and repairs. The signed locator is preserved with [R14.6](../R14.6/artifacts/communications/2014-05-onion-welcome.asc).

Every preserved observer received the same public body. The locator was signed on 2 April and delivered on 2 May. [R16.1](../R16.1/) later names Liber Primus as the way and assigns authored roles to its words, meaning and numbers.

The complete public image set and canonical transcriptions survive. The live onion, an authenticated operation for consuming the book, and R14.6's private submission and callback records are unavailable. Community section labels remain indexing conventions.
